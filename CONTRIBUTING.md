# Contributing — HackMe App

Thanks for helping the Useful PoW Index.

By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Before a PR

1. Keep changes focused; prefer English for new user-facing copy.
2. Do not commit secrets or local-only paths.
3. Smoke-check touched HTML pages in a browser.

## Security

Private reports only — see [SECURITY.md](SECURITY.md).
