# Security policy — HackMe App (Useful PoW Index)

## Supported

Current `main` of this registry prototype.

## Reporting

**Do not** open public issues for exploitable security bugs.

1. [https://hackme.tech/contacts.html](https://hackme.tech/contacts.html)
2. Include repro, impact, and affected page/script.

## Scope

In scope: XSS, open redirects, injection in listing/docs pages, secret leaks in
the static site.

Out of scope: disputes about project listings, third-party sites linked from the
index, phishing clones (report to us + host).
