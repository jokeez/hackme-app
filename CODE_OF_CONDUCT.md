# Contributor Covenant Code of Conduct (HackMe App)

## Our Pledge

We pledge to make participation in the Useful PoW Index community a harassment-free
experience for everyone.

## Our Standards

**Positive:** empathy, respectful disagreement, constructive feedback.  
**Unacceptable:** harassment, hate speech, doxxing, spam, phishing, malware,
stolen credentials, or posting secrets.

## Security

Report vulnerabilities privately via [hackme.tech/contacts.html](https://hackme.tech/contacts.html).
See [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may remove content or restrict access for violations. Contact:
[hackme.tech/contacts.html](https://hackme.tech/contacts.html).
